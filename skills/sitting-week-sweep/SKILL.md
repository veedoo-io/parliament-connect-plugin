# Sitting-week sweep

The recurring version of the job: not "find the clip where X said Y", but "did
anything worth clipping happen since I last looked".

## What to do

1. Establish which MP. If the conversation has not named one, ask — the sweep is
   per-member, and guessing wastes a query.
2. Work out the current sitting week. Sittings run Monday to Thursday with
   Friday sitting only sometimes, and recess breaks the pattern, so derive the
   window from today's date rather than assuming a full week. If the House has
   been in recess, say so instead of reporting an empty week as silence.
3. Search that member over that window.
4. Group what comes back **by sitting day**, most recent first. A flat list
   loses the thing the reader is looking for, which is the shape of the week.

## What to hand back

For each day, the clips from that day, and for each clip: what was said, in
enough words to judge it, and the anonymous share link so anything worth using
can go straight out.

Lead with the day that has something on it. If the week is empty, say the week
is empty and give the last day that was not — "nothing since Tuesday" is a
useful answer; a bare "no results" is not.

Coverage, query technique, and link choice are described in the Parliament
Connect clip-research context; this sweep follows all of it.
